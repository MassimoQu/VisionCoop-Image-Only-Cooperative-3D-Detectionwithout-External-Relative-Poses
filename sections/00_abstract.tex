\begin{abstract}
Camera-only cooperative perception extends sensing horizons without expensive LiDAR, yet practical deployment is severely degraded by spatial misalignment from external localization errors. While intermediate feature fusion collapses into negative collaborative gain under noise and two-stage box registration remains bounded by monocular depth uncertainty, 3D visual foundation models offer a promising route toward pose-free cooperation. However, adapting them exposes a fundamental \emph{reconstruction-to-detection gap} characterized by surface-to-center disparity, scalar depth ambiguity, and dense representation overhead. We present \method{}, an end-to-end framework directly coupling a shared 3D visual geometry model to cooperative 3D bounding box detection without externally supplied inter-vehicle poses at inference. Camera intrinsics and fixed intra-vehicle rig calibration remain known. \method{} introduces \emph{Surface-Guided Query Initialization}, which lifts surface tokens and aggregates learned offset votes toward latent object centroids, and \emph{Depth-Guided Iterative Query Refinement}, which uses evolving 3D box hypotheses as adaptive local frames to translate ambiguous depth into structured, rotation- and scale-normalized geometric feedback. In multi-vehicle OPV2V evaluations, \method{} maintains 44.52\% scale-aligned BEV $\text{AP}_{.5}$ across the reported noise grid; it surpasses V2X-ViT between $k=2$ and $k=4$, whereas feature fusion drops by up to 72.2\%. All AP values use scale-aligned scoring, while metric-scale recovery is reported separately. The geometric interface improves over naive scalar concatenation by +19.68 percentage points and direct query without depth by +7.31 percentage points. Finally, the recorded test-set inference benchmark gives \method{} a normalized inference cost of 0.55$\times$ the pseudo-point-cloud PointPillar route. On DAIR-V2X, cross-domain pose fine-tuning reaches 0.706\,m translation and 0.428$^\circ$ rotation errors, providing preliminary transfer evidence across vehicle-roadside viewpoints without externally supplied inter-vehicle poses.
\end{abstract}
